# Security Policy

## Reporting a Vulnerability

If you discover a security or licensing vulnerability in Deskland, **please do not open a public GitHub issue**.

Instead, please report it privately by emailing **hello@deskland.app** with:
- A brief description of the issue
- Steps to reproduce (if applicable)
- The app version and operating system you tested on

We will review your report as soon as possible and let you know once a fix is ready.
